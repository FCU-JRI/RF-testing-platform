Triage roles use standard default label strings (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repo documentation layout (`CONTEXT.md` + `docs/adr/`). See `docs/agents/domain.md`.
